A fast, dependency-free drop-in for make.fun's csv-reader 1.0.0: `solve.js` answers every CSV input exactly as csv-reader does — same columns, rows and broken-row errors — but reads the text with bulk native scans instead of one character at a time, so it runs about twice as fast on the competition's drawn sets.

## Run it

```sh
node main.ts
```
